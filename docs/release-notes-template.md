# Release 说明模板

发版时从此模板起稿（标题 `vX.Y.Z`，双语 README 已同步为对应版本）。「安装」段为固定内容，逐字保留；「新增/修复」按实际内容填写，没有的节整节删掉。

```markdown
## 新增

- （功能点，用户视角描述收益，不写实现细节）

## 修复

- （问题描述 → 修复后行为）

## 安装

- **Windows（Win11 x64）**：下载 `Shiyane_<版本>_x64-setup.exe` 双击安装；SmartScreen 提示时选「更多信息 → 仍要运行」。无需管理员权限与任何运行库；文件转字幕需在设置中配置阿里云 OSS
- **macOS（Apple Silicon）**：下载 DMG，拖入「应用程序」。安装包未做开发者签名，首次打开若提示「已损坏」（系统对网络下载的未签名应用的隔离标记，文件本身完好），在终端执行一次即可正常打开：`xattr -cr /Applications/Shiyane.app`。首次使用实时字幕需在 系统设置 > 隐私与安全性 > 屏幕录制 中授权
```

> 若后续接入 Apple 开发者签名 + 公证或 Windows 代码签名，先更新本模板与双语 README 安装段，再发版。
